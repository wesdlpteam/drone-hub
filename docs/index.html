Drone Hub

Fly CoDrone EDU drones from iPads. No apps, no cables on the iPads.

⬇️ Get Drone Hub for Windows
  1. Run DroneHub.exe on the laptop the drone controllers plug into. (First time, Windows may ask: choose More info → Run anyway, and Allow network access.)
  2. The Teacher Screen opens with a giant QR code.
  3. Kids point their iPad cameras at it and fly. That's it!

No drones plugged in? It runs Practice Mode with six virtual drones, great for coding lessons with zero hardware. Includes 5 coding levels, from picture blocks for pre-readers up to real Python.

Free and open source: view the code on GitHub. Made by the Wesley College Digital Learning & Practice team.
