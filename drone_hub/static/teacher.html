Drones

If iPads can't connect
  • First run: if Windows asked about the network, click Allow. If it was blocked, restart the hub and allow it.
  • Make sure the iPads are on the same Wi-Fi as this laptop.
  • Still stuck? Turn on this laptop's Mobile hotspot (Settings → Network & internet) and join the iPads to it, then restart the hub.
Flying more than one drone
  • Plug extra controllers in with a USB hub before starting the hub.
  • Each drone gets a colour name and its lights match — put matching coloured tape on each drone and controller pair.
  • Kids pick their drone by colour after scanning the QR code.
Make it an app icon on the iPads (one time)
  • Open the page in Safari, tap the Share button, then Add to Home Screen.
  • A "Drone Pilot" icon appears and opens full screen like a real app.
